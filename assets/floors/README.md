# 공학관 평면도 출처

공학관 1층과 2층 원본 평면도는 국민대학교 공과대학 건물지도에서 제공한다.

- 출처: https://engineering.kookmin.ac.kr/engineering/etc/engineering-floor-guide.do
- 1층: https://engineering.kookmin.ac.kr/_res/kookmin/engineering/img/common/floor_1F.png
- 2층: https://engineering.kookmin.ac.kr/_res/kookmin/engineering/img/common/floor_2F.png
- 확인일: 2026-07-13

원본 PNG는 실내 공간 데이터를 제작·검수하기 위한 참고자료다. 앱 런타임에는
포함하거나 표시하지 않고, 사용자는 별도로 가공한 방·복도·수직 이동 코어
폴리곤만 본다. 외부 배포 전에는 학교 측 사용 범위를 확인한다.
